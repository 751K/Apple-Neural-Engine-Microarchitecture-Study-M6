# Substack posts

The report body (chapters 4–17 of `final_report/en.md`) split into 13 Substack posts, text unchanged.
Generated by `tools/substack/build.py`; do not edit the HTML by hand.

```bash
python3 tools/substack/build.py --lang en          # rebuild posts and table images
python3 tools/substack/build.py --lang en --no-tables   # rebuild posts only
```

Needs `markdown-it-py` and Google Chrome.

## Layout

| Path | Contents |
|---|---|
| `en/index.md` | Post list with titles |
| `en/paste/NN.html` | Posts for pasting into Substack; images use GitHub raw URLs |
| `en/preview/NN.html` | Same posts with local images, for checking |
| `en/img/tX-Y.png` | Tables rendered as images (Substack has no tables) |

## What changed relative to the report

- Each post opens with one italic line naming the chapter and linking to the full report and the repository.
- Each post ends with the references it cites.
- Headings are promoted one level (`###` → H2) because the chapter title becomes the post title.
- Tables are images; their captions stay as text above them.
- Links to `../tools/…` and `../data/…` point to GitHub.

## Publishing a post

1. Table images load from the `substack/export` branch
   (`raw.githubusercontent.com/…/refs/heads/substack/export/substack/en/img/`), so push that branch after
   re-rendering tables. Report figures load from `main/figs/`. Substack copies pasted images to its own CDN.
2. Open `en/paste/NN.html` in a browser, select from the first italic line to the end, copy.
3. Paste into a new Substack post; type the title from `en/index.md`.
4. Check that the images were imported, then publish.
